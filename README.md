# Web Calculator

A modern, responsive web calculator built with vanilla HTML, CSS, and JavaScript. It features a sleek UI, calculation history, developer information, and customizable settings like haptic feedback and button sounds.

## ✨ Features

- **Basic Arithmetic:** Addition, subtraction, multiplication, and division.
- **Advanced Controls:** Percentage, sign toggle (`+/−`), and backspace.
- **Calculation History:** Stores your last 50 calculations locally so you can review or reuse them.
- **Settings Panel:** 
  - Haptic feedback (vibration on supported devices)
  - Button sounds (soft click tone)
  - Thousands separator for easier reading of large numbers
- **About the Developer:** A dedicated section with developer information.
- **Splash Screen:** A 2-second branded splash screen on load ("An Aliyan Production").
- **Keyboard Support:** Full keyboard input support for fast typing.
- **Responsive Design:** Works seamlessly on mobile, tablet, and desktop.
- **No Frameworks:** Pure vanilla HTML, CSS, and JavaScript. No dependencies.
